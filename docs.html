01START HERE

Quick start

PauzeControl has two parts: an Android controller and a native agent running on the Mac you want to control. They communicate over your private Tailscale network; this website does not relay the connection.

1
Prepare both devices

Install Tailscale on your Mac and Android device, and sign in to the same trusted tailnet.

2
Install the Mac agent

Build and install the agent from the project repository, then keep the pairing secret it prints private.

3
Add a Mac profile on Android

Enter the Mac's Tailscale IP or hostname, the agent port, and the pairing secret.

4
Verify the connection

Open the app dashboard. If the Mac appears offline, check network access, profile details, and permissions.

Important: never expose the Mac agent's control port to the public internet or share your pairing secret in an issue, screenshot, or chat.
02BEFORE INSTALLING

Requirements

MAC

Mac agent

  • macOS 14 (Sonoma) or newer.
  • Tailscale installed and connected.
  • Git and Xcode Command Line Tools for building from source.
  • Screen Recording permission for Live Screen; Accessibility for supported input control.
ANDROID

Controller app

  • Android 8.0 (API 26) or newer.
  • Tailscale installed and signed in to the same trusted network.
  • A compatible PauzeControl build.

Keep the Android app and Mac agent on compatible versions. Newer features may not work when one side is running an older build. Check the release notes before updating.

03MAC SETUP

Install the Mac agent

Run these commands in Terminal on the Mac you intend to control. If the command-line tools are already installed, skip the first command.

1 · Install command-line tools
xcode-select --install
2 · Download the repository and enter the Mac project
git clone https://github.com/PauzeDevs/PauzeControl.git
cd PauzeControl/mac
3 · Build and install
swift package dump-package
swift build -c release
./install.sh

The installer registers the agent as a user LaunchAgent and prints a pairing secret. Store that secret securely; anyone who obtains it may be able to authenticate to your device, depending on the active build and network access.

Build issue? Check that swift --version and git --version work, then review the agent logs at ~/Library/Logs/PauzeControl/stderr.log.
04ANDROID SETUP

Prepare Android

Install a PauzeControl Android build distributed through your approved project channel. Check the app repository for the current release notes and package details; this website does not mirror APK files.

  1. Open Tailscale and confirm the device is connected to the same trusted tailnet as your Mac.
  2. Open PauzeControl and navigate to Settings → Device Studio, then add a Mac profile if that screen is available in your build.
  3. Keep the profile name recognisable so you can distinguish it from other Macs.
  4. If a feature shown in these notes is missing, verify the installed app version. Not every feature is available in every release.

05PAIRING

Connect your devices

In the Android app's Mac profile, use the Mac's Tailscale IP address or hostname. Enter the host only—do not include http:// or a URL path.

Host

Your Mac's Tailscale IP or hostname.

Port

47777 by default, unless you changed the agent configuration.

Pairing secret

The secret printed by the Mac installer. Treat it like a password.

Confirm the connection

  • Make sure both devices show as connected in Tailscale.
  • Check the host and port in the active profile.
  • Confirm the Mac agent is running and required macOS permissions have been granted.
  • If authentication fails, verify the pairing secret and confirm both devices use compatible builds.
06MACOS PRIVACY

Permissions

Grant permissions only for the features you intend to use. The exact prompts depend on the macOS version and the capability being tested.

Screen Recording

Required for capturing the Mac display for Live Screen. Restart the agent after changing this permission.

Accessibility

Needed for supported remote mouse, keyboard, and input-control features.

Input Monitoring

Enable only if the restriction feature in your build explicitly requires it.

Network access

Tailscale connectivity and local firewall settings affect whether Android can reach the agent.

07SECURITY

Privacy and safe use

  • Keep access private. PauzeControl is designed to use a trusted Tailscale network. Do not port-forward the agent's control port to the public internet.
  • Protect pairing secrets. Never publish secrets, access tokens, or unredacted authentication logs.
  • Transfer carefully. Start with a small, non-sensitive file and verify it arrived intact. Retain your original until the transfer is confirmed.
  • Use permissions deliberately. Enable only the macOS permissions required for the features you want to use.
  • Use authorised devices. Control only Macs you own or have permission to administer.

Clipboard operations are intended to be user-initiated, not continuous background collection. Review the app's current release notes for version-specific transfer limits and behaviour.

08TROUBLESHOOTING

Common issues

Android shows the Mac as offline
  • Reconnect Tailscale on both devices and verify they are in the same tailnet.
  • Check the Mac's Tailscale IP or hostname and port 47777.
  • Confirm the Mac agent is running and the correct profile is active.
  • Check the pairing secret and the Mac agent's error log.
Live Screen is black or keeps reconnecting
  • Confirm Screen Recording permission is enabled on the Mac.
  • Restart the agent after changing permissions.
  • Try a lower stream quality if the network is unstable.
Clipboard, file transfer, or audio controls fail
  • Check that the Android app and Mac agent both support that feature.
  • Confirm the correct Mac profile is selected.
  • Review the Mac agent's error log for details.
The Android app will not update

An APK update generally needs to be signed with the same certificate as the installed app. A debug build may use a different key. Back up local data before uninstalling an app to resolve a signing mismatch.

09SUPPORT

Report an issue

Good reports describe one reproducible problem. Include:

  • Android app version and Mac agent version.
  • Android device model and macOS version.
  • Steps to reproduce, expected result, and actual result.
  • Relevant error messages or redacted logs.
Remove private information first. Do not attach pairing secrets, passwords, access tokens, private files, or logs that expose credentials.
